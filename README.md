# Bookish E-Commerce Store

A bookstore e-commerce website built with React and TypeScript (frontend only).

## Features
- Home page with featured books, shop by category and editorial banner
- Product catalog with search and category filter
- Wishlist
- Shopping cart with quantity updates
- Checkout with card payment validation
- Order confirmation page
- Responsive design
- Style guide page

## Technologies
- React 18 + TypeScript
- Vite
- CSS (custom styles per page)
- Vitest + React Testing Library
- Git and GitHub (feature branches and pull requests)

## Setup
1. Clone the repository:
   git clone https://github.com/Rayyanalmousa/React-Ecommerce-Project.git
   cd React-Ecommerce-Project
2. Install dependencies:
   npm install
3. Start the development server:
   npm run dev
4. Run the tests:
   npm test
5. Build for production:
   npm run build
